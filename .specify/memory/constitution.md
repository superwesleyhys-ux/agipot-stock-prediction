# AGIPOT Research Constitution

1. Reproduce inputs, code, dependency versions, seeds, label definitions and splits.
2. Historical predictions use only observations, model versions and labels available at that time.
3. Final holdout results do not select hyperparameters or model families.
4. Formula scores and heuristic confidence are not probabilities or demonstrated returns.
5. Every registered trial must end in a recorded success, failure or abort; retries are distinct attempts.
6. Evidence judgments retain original source spans and stable entities; summaries are display-only.
7. Keep data adapters optional and fail explicitly when prerequisites are missing.
8. Validate the installed distribution and preserve compatibility with the declared Python versions.
