# Changelog

## 0.1.0

- First standalone public extraction of AGIPOT stock research and related scoring technology.
- Unified offline API and CLI, multi-horizon distillation, online intraday model, factor scoring, formula library and validation utilities.
- Documented input schemas, score meanings, provenance, and statistical limitations.
- Correctness fixes for temporal splits, capped weights, zero-score handling, strict finite inputs, streaming feature parity and drawdown sorting.
- Synthetic examples, regression tests, wheel/sdist builds and a GitHub Actions template (not yet enabled).
